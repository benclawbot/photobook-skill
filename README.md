# Photobook skill

A Codex skill for turning a supplied photo collection into a visually curated, varied, themed photobook PDF.

## Install

Copy this skill folder into your Codex skills directory. The entrypoint is `SKILL.md`; the bundled Pecita font and its SIL Open Font License are in `assets/`.

## Use

Ask Codex to create or revise a photobook from a set of photos. The skill guides inventory and duplicate checks, visual theme curation, varied layouts, typography, PDF generation, and rendered-page review.
